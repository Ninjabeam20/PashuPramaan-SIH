# Create a desktop web dashboard for the **Laboratory Technician role** of an existing government livestock antimicrobial surveillance platform called **PashuPramaan**.

IMPORTANT: This screen must look like it belongs to the **exact same product and design system** as an existing Farmer portal and Veterinarian portal. Do not redesign the brand. Maintain a consistent visual language throughout.

## Overall visual style

Use a calm, premium, trustworthy government-healthcare interface.

* Warm off-white / very light cream page background
* Deep forest green as the primary brand and action colour
* Muted sage green for subtle accents
* White content cards with very subtle warm-grey borders
* Minimal shadows
* Rounded corners, approximately 10–14px, not excessively rounded
* Large elegant serif typography for major page headings
* Clean modern sans-serif typography for navigation, labels, tables, metadata and buttons
* Thin-line minimal icons
* Spacious layout with generous padding and whitespace
* No gradients
* No glassmorphism
* No neon colours
* Avoid flashy startup/SaaS aesthetics
* The feeling should be: **professional Indian government digital service + veterinary health + laboratory operations**

Use restrained semantic colours:

* Deep green for compliant, complete and primary actions
* Soft amber for pending, review required and warnings
* Muted red for hold, critical or non-compliant states
* Neutral grey for inactive and informational states

## Overall composition

The dashboard should feel calm and structured.

The visual hierarchy should be:

1. Greeting and Laboratory Dashboard heading
2. Current workload summary
3. Urgent actions requiring immediate attention
4. Testing queue
5. Recent activity

Do not overcrowd the screen.

This is not a generic laboratory dashboard. It is specifically part of a **livestock antimicrobial usage, food safety, residue monitoring and traceability platform**.

The interface must communicate:

**Dispatch ID → Sample → Testing → Result → Verification → Release or Hold**

Keep the design highly polished, realistic, consistent, and production-ready.
